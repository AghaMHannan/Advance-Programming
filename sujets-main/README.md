# Programmation Avancée — sujets

Les énoncés seront publiés dans ce dépôt au fil de l'année.

Chaque étudiant :

- pousse ses programmes sur la branche `solution` ;
- un juge automatique les compile et les exécute sur des instances cachées ;
- reçoit ses verdicts sur la branche `retour`, qu'il ne peut pas modifier,
  et qu'il consulte avec `git fetch origin retour`.
